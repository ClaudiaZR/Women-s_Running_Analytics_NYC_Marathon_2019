# Tableau Dashboard — Women's Running Analytics

## Dashboard

**Name:** Running Through the Ages

**Dataset:** NYC Marathon 2019 results

**Focus:** Women's participation and marathon finish-time performance across age groups.

## Analysis and Visualizations

The dashboard includes five visualizations:

1. Women's Age Group Distribution
2. Women's Average vs. Median Finish Time by Age Group
3. Women's Finish Time Distribution by Age Group
4. Women's Fastest vs. Slowest Finish Time by Age Group
5. Women's Geographic Representation

Five KPI cards summarize total runners, female runners, and women's average, fastest, and slowest finish times.

## Tools and Techniques

- Tableau Public
- Calculated fields and age groups
- KPI cards
- Average and median comparisons
- Box plots and finish-time range comparisons
- Filters, formatting, and dashboard layout
